# To-Do List App

Uma lista de tarefas simples e elegante, desenvolvida para demonstração de habilidades em desenvolvimento web. Inclui animações suaves para adicionar, concluir e remover tarefas, com armazenamento persistente no navegador.

## Funcionalidades

- **Adicionar tarefas**: Digite e adicione novas tarefas com animação de entrada.
- **Marcar como concluída**: Clique em "Concluído" para riscar a tarefa com uma animação de linha crescente (da esquerda para a direita).
- **Remover tarefas**: Clique em "Apagar" para remover com animação de fade-out e escala.
- **Persistência**: As tarefas são salvas automaticamente no `localStorage` do navegador.

## Como usar

1. Clone ou baixe o repositório.
2. Abra o arquivo `index.html` em qualquer navegador moderno.
3. Comece a adicionar suas tarefas!

## Tecnologias utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilos e animações (transitions e keyframes).
- **JavaScript (ES6)**: Lógica interativa e manipulação do DOM.

## Estrutura do projeto

```
to-do-list/
├── index.html      # Página principal
├── style.css       # Estilos e animações
├── script.js       # Lógica JavaScript
└── README.md       # Este arquivo
```

## Personalização

- Para alterar cores, edite as variáveis no `style.css`
- Animações podem ser ajustadas nos `transition` e `@keyframes`.
- Adicione mais funcionalidades, como datas de vencimento ou categorias.
